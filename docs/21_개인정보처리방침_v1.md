## 1. 총칙
TripPot 팀(이하 "팀")은 이용자의 개인정보를 중요하게 생각하며, 개인정보 보호법 등 관련 법령을 지킵니다. 이 방침은 팀이 **실제로 처리하는 정보만** 적습니다.

## 2. 개인정보 처리 목적
| 목적 | 내용 |
|---|---|
| 회원 식별·로그인 | 소셜/이메일 로그인, 계정 상태(정상·탈퇴 유예·탈퇴) 관리 |
| 서비스 제공 | 모임·여행 생성과 참여, 예산 계획, 납부·지출 기록, 결산, 알림 |
| 함께 쓰는 기능 | 같은 여행 멤버에게 멤버 이름·프로필 사진·공동 기록 표시 |
| 커뮤니티 | 글·댓글·사진 게시(화면에는 익명 표시), 본인 글 수정·삭제 |
| 서비스 개선 | 화면 진입·주요 기능 사용 통계 분석 |
| 안전·문의 대응 | 부정 이용 확인, 문의 처리 |

## 3. 처리하는 개인정보 항목
### 3-1. 로그인 수단별 (제공자로부터 받는 값)
| 로그인 | 받는 값 | 앱 DB(`public.users`)에 저장 |
|---|---|---|
| 카카오 | 닉네임, 프로필 사진, 카카오 회원번호 | 이름, 프로필 사진 주소, 제공자 구분, 제공자 회원번호 |
| 구글 | 이름, 프로필 사진, 구글 계정 번호, 이메일 | 이름, 프로필 사진 주소, 제공자 구분, 제공자 회원번호 (**이메일은 앱 DB에 저장하지 않음**) |
| 이메일 | 이메일 주소, 비밀번호 | (앱 DB에는 이메일·비밀번호를 저장하지 않음) |

> 이메일 주소와 비밀번호는 인증 기반(Supabase Auth)의 계정 저장소에만 보관되며, 비밀번호는 복원할 수 없는 형태로 저장됩니다.

### 3-2. 프로필
이름, 프로필 사진, 여권 영문 이름(사용자가 직접 입력하는 경우), 알림 수신 설정.

### 3-3. 모임·여행
모임 이름, 멤버 관계와 역할, 여행지, 여행 기간, 예정 인원, 여행 스타일 선택값, 여행 상태(준비 중·여행 중·종료·취소 등), 여행장 지정, 함께 가는 사람의 이름(미가입자는 표시 이름만).

### 3-4. 초대·참여
초대 링크 토큰, 초대한 사람, 유효기간(발급 후 7일), 참여 의사 요청과 처리 결과(대기·수락·거절·취소).

### 3-5. 예산·자금 (모두 **모의 데이터 또는 직접 입력값**)
목표 금액, 카테고리별 추천·개인화·확정 금액, 납부 예정·완료 금액, 지출 항목명·금액·일시·메모, 결산 결과.
서비스는 실제 금융기관 계좌에 연결되지 않으며, 화면의 계좌·잔액은 앱이 만든 **테스트용 모의 값**입니다. 실제 계좌번호·실거래내역·인증 정보는 수집하지 않습니다.

### 3-6. 커뮤니티
글·댓글 내용, 첨부 사진, 반응(좋아요·저장), 글에 연결한 여행지 이름.
**화면에는 작성자 이름·프로필 사진이 표시되지 않습니다.** 다만 본인 글 판별과 수정·삭제를 위해 작성자 식별자가 내부에 저장됩니다.

### 3-7. 알림
알림 종류·제목·본문·읽음 시각, 관련 여행, 그리고 알림을 만든 사람의 식별자(초대한 사람·행동한 사람).
**원격 푸시 발송은 하지 않으며 푸시 토큰을 수집하지 않습니다.** 기기 내 예약 알림만 사용합니다(알림 권한은 기기에서 허용한 경우에만).

### 3-8. 이용 기록·분석
비로그인 구간을 잇기 위한 익명 식별자, 회원 식별자, 화면·기능 이벤트 이름과 부가 값, 실행 환경 구분.
분석 도구(Amplitude)로는 **정식 실행 환경에서만** 전송되며, 개발 환경에서는 전송하지 않습니다. 분석 도구에는 앱 사용 기록·기기 정보·대략적인 지역·회원 식별자가 전달됩니다.

### 3-9. 저장 파일
프로필 사진, 커뮤니티 사진, 영수증 사진.

## 4. 수집 방법
- 이용자가 로그인 수단을 선택하고 제공자가 전달하는 값
- 이용자가 앱에서 직접 입력·업로드하는 값
- 서비스 이용 과정에서 자동으로 기록되는 이용 로그

별도의 오프라인 수집이나 제3자로부터의 구매는 없습니다.

## 5. 처리 및 보유기간
| 구분 | 기간 |
|---|---|
| 회원 정보·서비스 이용 기록 | 회원 탈퇴 시까지 (탈퇴 신청 후 **30일 유예기간** 포함) |
| 알림 기록 | 생성 후 **730일(약 2년)** 경과 시 자동 삭제 |
| 공동 여행 기록(모임·여행·예산·납부·지출·정산) | 함께한 다른 이용자의 기록이므로 **탈퇴 후에도 보존**하며, 탈퇴자는 `탈퇴한 회원`으로만 표시 |
| 탈퇴자 개인 식별정보 | 최종 탈퇴 시 삭제·비식별 처리 (§10) |
| 테스트 종료 후 | `[확정 필요: 테스트 종료 후 전체 삭제 시점 — 설치 안내 페이지에는 "테스트 종료 1년 뒤 삭제"로 공지되어 있음. 이 값을 그대로 확정할지 팀이 정해야 함]` |

법령에 별도 보존 의무가 있는 경우 그 기간을 따릅니다. 서비스는 전자금융거래·전자상거래 결제를 제공하지 않으므로 그에 따른 거래기록 법정 보존은 적용하지 않습니다.

## 6. 개인정보의 제3자 제공
팀은 이용자의 개인정보를 제3자에게 **판매하거나 마케팅 목적으로 제공하지 않습니다.**
다만 서비스 구조상 다음이 **다른 이용자에게 보입니다.**
| 대상 | 보이는 정보 |
|---|---|
| 같은 모임·여행의 멤버 | 이름, 프로필 사진, 그 여행의 예산·납부·지출·정산 기록, 현재 참여 가능 여부 |
| 초대 링크를 받은 사람 | 여행지, 기간, 예정 인원, 초대한 사람의 이름 |
| 모든 이용자(커뮤니티) | 글·댓글·사진, 글에 연결한 여행지 이름 (**작성자 이름·프로필 사진은 표시하지 않음**) |

## 9. 파기 절차 및 방법
1. 보유기간이 지나거나 처리 목적이 끝난 개인정보는 지체 없이 파기합니다.
2. 전자적 파일은 복구할 수 없는 방법으로 삭제하고, 저장소의 사진 파일은 저장소에서 삭제합니다.
3. 다른 이용자와 함께 만든 공동 기록은 파기 대상이 아니며, 그 안의 탈퇴자 식별정보만 비식별 처리합니다.

## 10. 회원탈퇴 시 처리 (정책 v2와 1:1)
1. **상태** — 정상(ACTIVE) / 탈퇴 유예(PENDING_WITHDRAWAL) / 탈퇴 완료(WITHDRAWN)
2. **유예기간 30일** — 신청 시각 + 30일. 그 동안 일반 서비스 이용은 중단되고 탈퇴 취소 화면만 열립니다.
3. **경계** — 신청 + 30일 **미만**까지만 취소할 수 있습니다. 30일에 도달하면 취소할 수 없고 화면에 `탈퇴 처리 중`이 표시됩니다.
4. **취소** — 이용자가 직접 [탈퇴 취소]를 눌러야 복구되며, 같은 계정·같은 관계로 돌아옵니다.
5. **최종 탈퇴 시 하는 일**
   - 이름은 `탈퇴한 회원`으로 바꾸고, 여권 영문 이름·프로필 사진 주소·로그인 제공자 식별자·알림 설정을 지웁니다
   - 모임·여행 멤버 자격을 모두 `나감` 상태로 바꾸고, 남아 있던 참여 의사는 취소 처리합니다
   - 본인에게 온 알림을 삭제하고, 다른 이용자의 알림함에 남은 **이 사람이 만든 알림**(초대한 사람·행동한 사람으로 기록된 것)을 삭제합니다
   - 인증 계정을 삭제합니다. 이후 같은 수단으로 다시 가입하면 **새 이용자**이며 과거 기록과 연결되지 않습니다
6. **여행 데이터** — 종류에 따라 다릅니다.
   - **다른 이용자가 한 번이라도 실제로 참여한 적 있는 여행**: 그대로 **보존**합니다. 함께한 사람의 기록이기 때문입니다. 탈퇴자는 `탈퇴한 회원`으로만 표시됩니다
   - **혼자만 참여한 여행**(개인 여행이든 모임 여행이든): 그 여행과 그 여행에만 속한 기록(예산·납부·지출·정산·초대·참여 요청)을 **삭제**합니다
   - 여행이 하나도 남지 않고 다른 멤버도 없었던 모임은 함께 정리합니다
   - 초대 링크만 만들었거나, 상대가 참여 의사만 보냈던 경우는 "실제 참여"로 보지 않습니다
7. **커뮤니티** — 글·댓글은 처음부터 익명으로 표시되며, 탈퇴 여부도 표시하지 않습니다.
8. **프로필 사진 파일** — 저장소의 실제 파일 삭제는 별도 정리 절차로 수행합니다. `[확정 필요: 정리 작업의 정기 실행 등록 여부 — 현재 등록이 확인되지 않았습니다]`

## 11. 정보주체의 권리와 행사 방법
1. 이용자는 자신의 개인정보에 대해 **열람·정정·삭제·처리정지**를 요구할 수 있습니다.
2. 앱에서 직접 할 수 있는 것: 이름·프로필 사진 변경, 알림 설정 변경, 게시물 수정·삭제, 여행 나가기, 회원탈퇴.
3. 그 밖의 요구는 제14항의 문의 창구로 보내 주시면 지체 없이 처리합니다.
4. 법정대리인을 통한 행사도 가능합니다.

## 12. 자동 수집 장치와 이용 기록
1. 앱은 쿠키를 사용하지 않습니다.
2. 이용 통계를 위해 익명 식별자와 이벤트 기록을 남기며, 정식 실행 환경에서만 분석 도구로 전송합니다.
