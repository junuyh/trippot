## 3. docs/archive/

`archive/` 는 **원본 기획 종합본 보관용**이다. (`260826_TripPot_서비스_기획_종합본_v0.1.md`, 865줄)

- **평소에 읽지 않는다.** 위 문서들이 이 원본에서 정리된 구현 기준 문서다.
- 초기 기획 의도를 반드시 확인해야 할 때만, 사람이 명시적으로 요청한 경우에 읽는다.
- archive 의 내용이 최신 버전 문서와 다르면 **최신 버전 문서가 맞다.**

## 4. 버전 관리 규칙

- **기존 문서를 수정하지 않는다.** 이미 만들어진 `_v1` / `_v2` 파일은 읽기 전용이다.
- 변경이 필요하면 **다음 번호의 파일을 새로 추가한다.** 예: `05_ERD_v2.md`
- **같은 번호에 여러 버전이 있으면 높은 버전이 기준이다.** 낮은 버전은 이력으로 남긴다.
- 새 버전을 추가하면 이 README 의 **문서 목록과 작업별 매핑을 함께 갱신한다.**
- 문서 상단 메타 표(문서 상태·작성일·변경 사유·이전 버전)를 새 파일에도 유지한다.
- **결번이 생기면 사유를 새 파일 메타에 적는다.**
  예: `04_화면목록_v3.md` 는 v2 결번 — 담당자 미확정으로 v2를 작성하지 않았다.

## 5. 미반영 변경사항

구현이 문서보다 앞서 나간 지점과, 문서에 아직 결정이 없는 지점을 모은다.

**7~9번은 구현을 막는 미결정 사항이다.** 해당 화면 착수 전에 사람에게 확인한다.
