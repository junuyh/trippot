## 3. docs/archive/

`archive/` 는 **원본 기획 종합본 보관용**이다. (`260826_TripPot_서비스_기획_종합본_v0.1.md`, 865줄)

- **평소에 읽지 않는다.** 위 01~06 이 이 원본에서 정리된 구현 기준 문서다.
- 01~06 에 없는 초기 기획 의도를 반드시 확인해야 할 때만, 사람이 명시적으로 요청한 경우에 읽는다.
- archive 의 내용이 01~06 과 다르면 **01~06 이 맞다.**

## 4. 버전 관리 규칙

- **기존 문서를 수정하지 않는다.** `01_*_v1.md` ~ `06_*_v1.md` 는 읽기 전용이다.
- 변경이 필요하면 **`_v2` 파일을 새로 추가한다.** 예: `05_ERD_v2.md`
- `_v2` 를 추가하면 이 README 의 문서 목록과 작업별 매핑을 함께 갱신한다.
- 같은 번호에 v1·v2 가 함께 있으면 **높은 버전이 기준**이다. v1 은 이력으로 남긴다.
- 문서 상단 메타 표(문서 상태·작성일·변경 사유·이전 버전)를 새 파일에도 유지한다.
