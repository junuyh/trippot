## 0. 이 문서를 읽는 법

이 문서는 **서비스 전체 구조를 한눈에 보기 위한 트리**다.

- **화면 ID와 라우트는 `04_화면목록_v3.md` 가 기준이다.** 04 v3 에 없는 화면은 위 표기 규칙(가칭)을 따른다. 이 문서의 번호(1-1, 2-2 등)는 구조 이해용 참조 번호이며 코드에 사용하지 않는다.
- 트리의 하위 항목이 반드시 별도 화면인 것은 아니다. 한 화면 안의 섹션 · 시트 · 모달인 경우가 많다. 실제 화면 단위는 화면목록을 따른다.
- **트리에는 현재 화면에 실제로 있는 것만 적는다.** 문서에만 있던 항목은 각 절의 `🔁 변경` 블록에 이력으로 남긴다. 파일은 있으나 진입 경로가 없는 것은 `[고아]`, 범위에서 뺀 것은 `[제외]`, 결정이 없는 것은 `[검토 필요]` 로 표시한다.
- `→` 는 이동(라우팅)이다. 시트·모달·오버레이는 이동이 아니라 제자리에서 열린다.
- 화면 흐름과 분기 조건은 `02_유저플로우` 가, 기능 우선순위는 `03_요구사항정의서` 가 기준이다. (둘 다 v2 갱신 대상 · 18 §13)
- 문서와 코드가 어긋난 곳은 `18_서비스비교정리.md` 의 행 번호(`18 §n-m`)로 근거를 가리킨다.

#### 2-6-1. 결산 중 이동 흐름

```
TRIP-HOME-02 (ENDED)          HOME-01 지난 여행 카드
  ↓ 정산 유도 카드               ↓ 결산하기 →
SETTLE-01
  ├─ 확인할 거래 ──────→ FUND-04 (?filter=review) → 탭 → 상세 시트 (카테고리 변경 · 확인 완료)
  └─ 지출 미연결 계획 ──→ 해당 카테고리 BUDGET-02 → 계획 항목 → 지출 직접 입력 / FUND-03 계획 연결
```

**미분류 거래를 임의의 BUDGET-02 로 보내지 않는다.** 카테고리가 없는 거래는 '어느 카테고리 화면인가' 에 답할 수 없다. 반대로 **지출 미연결 계획은 이미 카테고리가 정해져 있다.** 그래서 BUDGET-02 로 보낸다. (v2 유지)

#### 2-6-2. 결산 상태 — 새 상태값을 만들지 않는다

| 상태 | 뜻 | 전환 |
|---|---|---|
| `ENDED` | **결산 중.** 여행 일자는 끝났고 거래 검토가 남았다 | 종료일 다음 날 여행 홈 진입 시 자동 |
| `SETTLED` | **결산 완료.** `settlements.confirmed_at` 이 채워졌다 | SETTLE-01 [정산 확정하기] 에서만 |

`SETTLEMENT_IN_PROGRESS` 같은 새 상태를 만들지 않는다. `ENDED` 가 이미 그 뜻이다. (v2 유지) 취소 흐름이 붙으면서 `CANCEL_PENDING` · `CANCELED` 가 추가됐지만 결산과는 무관하다 (§3-4-2).

#### 2-6-3. 상태별 수정 권한 — 코드가 실제로 강제하는 것

**화면을 새로 만들지 않는다.** 같은 화면에서 데이터와 권한만 바꾼다.

| 동작 | `PLANNING` | `TRAVELING` | `ENDED` (결산 중) | `SETTLED` (결산 완료) | 근거 |
|---|---|---|---|---|---|
| 카테고리 설정 예산 수정 (BUDGET-02 ✎) | ✅ | ❌ | ❌ | ❌ | `canEditBudget = PLANNING` (18 §4-2) |
| 계획 추가·수정·삭제 · 개인화 토글 | ✅ | ✅ | ❌ | ❌ | `canEditPlan` |
| 지출 직접 입력 (BUDGET-02) | ✅ | ✅ | ✅ | ❌ | `canEditSpending` |
| 입출금 기록 (FUND-01) | ✅ | ✅ | ✅ | ✅ | 상태 분기 없음 |
| 거래 분류 · 계획 연결 (FUND-03 상세) | ✅ | ✅ | ✅ | ❌ | `canEdit = 출금 && !SETTLED` |
| 거래 분류 · 계획 연결 · 삭제 (FUND-04 목록 시트) | ✅ | ✅ | ✅ | ✅ | 상태 분기 없음 |
| 여행 정보 수정 (일정 · 인원) | ✅ | ✅ | ❌ | ❌ | TRIP-EDIT 차단 |
| 예산 확정 ([이 금액으로 확정하기]) | ✅ | ✅ | ✅ | ✅ | 조건은 목표액 0 뿐 |

> v2 는 "설정 예산 수정 PLANNING / TRAVELING ✅" 였다. **TRAVELING 에서는 계획 항목만 고칠 수 있다.** (18 §4-2)
> ⚠️ FUND-04 목록 시트와 FUND-01 은 SETTLED 를 보지 않는다. FUND-03 과 다르다. (§8-1)

결산 완료 후 거래를 고쳐야 하면 **결산을 다시 열어 `ENDED` 로 되돌리는** 기능은 아직 없다. `[검토 필요 · §8 I]`
