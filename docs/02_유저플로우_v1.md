# TripPot 유저플로우 v1

| 항목 | 내용 |
|---|---|
| 문서 상태 | 확정 초안 |
| 작성일 | 2026-08-27 |
| 변경 사유 | 최신 IA와 2-5 여행 유형 결과를 포함한 구현 기준 흐름 최초 생성 |
| 이전 버전 | 없음 |

## 1. 전체 흐름

```text
서비스 진입
→ 홈
├─ 진행 중 여행 → 2-2 진행 상태 여행 홈
├─ 종료 여행 → 2-2 종료 상태 여행 홈
├─ 모임 → 모임 상세
└─ 새 여행 → 2-1 여행 생성

2-1 여행 생성
→ 2-2 여행 준비 홈
→ 2-3 예산 상세
↔ 2-4 여행자금/입출금
→ 여행 종료
→ 2-6 여행 결산
→ 2-5 여행 유형 결과
→ 다음 여행 개인화
```

## 2. 2-1 여행 생성

1. `누구와 가나요?`
   - 개인
   - 기존 모임: 과거 데이터가 있으면 인사이트 반영/제외 선택
   - 신규 모임: 모임명·멤버 구성
2. 여행 기본정보
   - 여행지, 일정, 인원, 여행 스타일
3. 여행 예산·자금 설정
   - 추천받고 정하기 또는 정해둔 예산 입력
   - 두 경로 모두 예상 여행비 비교로 수렴
   - 카테고리 수정 후 목표 여행비 확정
   - 기존/신규 계좌, 직접 입력, 0원 시작 중 선택
4. 생성 완료 → 2-2

## 3. 2-2 여행 준비 홈

**역할:** `우리 여행 준비가 지금 어느 정도 됐지?`에 답하는 종합 요약 화면.

- 여행 요약
- 목표·현재자금·준비율·부족금액
- 직접 입력/계좌 연결 상태 요약
- 8개 카테고리 가상 여행 금고
- 모임원 납부 현황(선택)
- 최근 여행자금 내역
- 예산 인사이트
- 여행 팁·보험
- 정보·예산·자금 수정 및 여행 종료

분기:

- 가상 금고 카테고리 선택 → 2-3
- 최근 내역 전체 보기 → 2-4
- 수기 사용자 계좌 연결 → 초기화·대체 경고 → 확인 시 계좌 잔액으로 전환
- 여행 종료 → 미분류/누락 거래 확인 → 2-6

## 4. 2-3 예산 상세

**역할:** `이번 여행에서 어디에 얼마를 쓸 계획이지?`에 답하는 예산 계획 화면.

- 전체 예산 현황
- 카테고리별 예상·준비·실제·잔여·준비율/사용률
- 카테고리 상세
- 세부 계획 항목 추가·수정·삭제
- 해당 카테고리 실제 지출
- 예산 인사이트와 카테고리 팁
- 보험 카테고리는 제휴 보험사 이동 제공

거래 선택 → 2-4 거래 상세.

## 5. 2-4 여행자금/입출금

**역할:** `실제 돈이 어디서 들어오고 어디에 나갔지?`에 답하는 금융 원장 화면.

- 현재 잔액·목표·부족금액
- 계좌/직접 입력 관리 방식
- 전체/입금/출금 내역
- 거래 상세 및 카테고리 수정
- 선택형 멤버 납부 현황

```text
2-3 계획 항목
→ 실제 결제
→ 2-4 거래 자동/수동 입력
→ 예산 카테고리 매핑
→ 2-3 실제 사용금액 갱신
→ 2-2 요약 갱신
```

## 6. 여행 종료·결산

1. 여행 종료 선택
2. 미분류/누락 거래가 있으면 거래 추가·분류 수정
3. 2-6 결산에서 전체 및 카테고리 예상 vs 실제 확인
4. 결산 확정
5. 개인/모임 데이터 누적
6. 2-5 여행 유형 결과 생성
7. 지난 여행 저장, 팁 작성/판매, 같은 멤버로 다시 만들기

## 7. 2-5 여행 유형 결과

**역할:** 결산 데이터를 재미있고 공유하고 싶은 결과로 재해석한다.

```text
결과 인트로
→ 대표 유형 이미지·유형명·한 줄 설명
→ 복수 보조 유형/특성 키워드
→ 간략한 예산·지출 근거
→ 이미지 저장 / 공유 / 상세 결산 / 다음 여행
```

근거 정보:

- 목표 여행비와 실제 여행비
- 가장 많이 지출한 카테고리
- 예상보다 많이 쓴 카테고리
- 예상보다 절약한 카테고리
- 대표 차이 금액 또는 비율

## 8. 모임·마이페이지·커뮤니티

- 홈/모임 메뉴/마이페이지의 `나의 모임`은 모두 같은 모임 상세로 이동한다.
- 마이페이지의 모임은 별도 기능 없이 단순 링크다.
- 커뮤니티는 팁 탐색·상세·구매·작성·판매를 제공한다.
- 마이페이지 커뮤니티 활동은 작성글, 댓글, 좋아요, 구매 팁, 판매 팁을 제공한다.

## 9. 주요 예외 정책

| 상황 | 처리 |
|---|---|
| 진행 여행 없음 | 최초/재방문 빈 상태 구분 |
| 계좌 연결 실패 | 수기 상태 유지, 초기화 금지 |
| 수기→계좌 전환 | 합산 금지, 확인 후 대체 |
| 납부 관리 미사용 | 관련 카드·알림 숨김 |
| 추천 데이터 부족 | 기본 범위 제공, 추정 한계 표시 |
| 거래 분류 불확실 | 사용자 확인·수정 허용 |
| 결산 전 미분류 거래 | 결산 확정 전 정리 유도 |
