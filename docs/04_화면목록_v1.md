## 1. 라우트 원칙

- 아래 라우트는 v1 구현 기준이다.
- 상세 리소스는 `:tripId`, `:groupId`, `:postId`, `:transactionId`를 사용한다.
- 팝업·바텀시트는 별도 라우트가 아닌 화면 내부 상태로 처리한다.
- 담당자 미지정 화면은 임의 배정하지 않는다.

## 3. 동일 Route의 상태 분기

`TRIP-HOME-01`과 `TRIP-HOME-02`는 같은 Route를 사용하며 `trip.status`로 UI를 분기한다.

| 상태 | 값 | 핵심 CTA |
|---|---|---|
| 준비 중 | `PLANNING` | 예산·자금 관리, 여행 종료 |
| 여행 중 | `TRAVELING` | 거래 기록, 사용 현황 확인 |
| 종료/결산 전 | `ENDED` | 결산 완료 |
| 결산 완료 | `SETTLED` | 유형 결과, 팁 작성, 다시 만들기 |

## 4. 팝업·바텀시트

- 목표 여행비 간단 수정
- 현재 여행자금 수정
- 여행 기본정보 일부 수정
- 계획 항목 추가·수정·삭제 확인
- 거래 카테고리 변경
- 수기 데이터 초기화·대체 경고
- 계좌 연결 해제
- 여행/모임/게시글 삭제 확인
